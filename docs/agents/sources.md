# Sources and extensions

Browse, local manga, extension repos, source filters and settings, FlareSolverr.

- Local manga come from Suwayomi's local source (id 0), which reads Mihon's layout: a folder per manga, a folder of images or a `.cbz`/`.zip` per chapter, `details.json` or `ComicInfo.xml`, `cover.jpg`. Its folder is the server setting `localSourcePath` (Settings "Local manga folder"; blank means `<root>/local`, `Storage.localFolder`); the server refuses a folder that does not exist. Browse lists it under Other whatever the languages, as Mihon's `GetEnabledSources`; global search, the languages panel and Migrate leave it out, as in Mihon. An empty popular or latest listing shows where to put manga. A backup carries local manga as Mihon does (`source` 0, `url` the folder name, chapter `url` `<folder>/<file>`), so the sync needs nothing special.
- Browse adds the Keiyoushi extension repo once per server and records that in meta `miharchy.repoPreset`, so a repo the user removes stays removed. Suwayomi rewrites a repo's `index.min.json` URL to `index.pb` and ignores removal by any other URL, so remove a repo by the `indexUrl` the server returns.
- A source's filters and settings are widgets its extension defines. `window/Widgets.js` parses both into one tree, edits it, and builds `fetchSourceManga`'s `filters` and `updateSourcePreference`'s `change`; `WidgetPanel.qml` shows it. Both address the server's full list by position, so hidden rows keep their place. Suwayomi hands filters to the source only in a SEARCH, so applying filters searches (`F` on a source); they live for the window's life and are never stored, as in Mihon. A setting saves at once (`S`) and Suwayomi reloads the source. Enter on an installed extension opens its details (`Extensions.details`: version, language, its sources); Enter on a source there opens the same settings panel, which BrowseView draws over the Extensions screen. Suwayomi has no per-source enable switch, so the details have none. `u` updates one extension and `U` all that have an update (`updateExtensions`).
- FlareSolverr is optional. The setup screen offers it as a Docker container bound to `127.0.0.1:8191` and then sets `flareSolverrEnabled` and `flareSolverrAsResponseFallback`. Without it, Cloudflare sources show a "needs FlareSolverr" message.
